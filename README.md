# Портфолио проектов

В данном репозитории собраны учебные, научно-исследовательскик и производственным проекты.

---

### 1. База данных для стоматологической клиники
Разработка информационной системы для хранения и обработки медицинских карт и цифровых снимков челюсти человека.
*   **Что сделано:** Спроектирована реляционная БД (3НФ), реализованы ролевая модель доступа, триггеры и функции. Написано приложение доступа с кэшированием и проведено исследование влияния индексов на скорость запросов.
*   **Стек:** PostgreSQL, C++, libpqxx, Redis, Qt 6, CMake.

### 2. Визуализация трёхмерного огня
Разработка ПО для реалистичной визуализации 3D-пламени в реальном времени с учётом внешнего освещения.
*   **Что сделано:** Реализован метод систем частиц, эмиссионная модель освещения и алгоритм z-буфера с аддитивным смешиванием. Проведен анализ производительности (FPS) в зависимости от количества частиц.
*   **Стек:** C++, Qt, CMake.

### 3. Управление реестром Docker-образов на базе Harbor 
Обзор и сравнительный анализ современных систем управления реестрами контейнеров.
*   **Что сделано:** Проведен анализ 30 решений по 10 критериям. Выполнено практическое развертывание Harbor на Ubuntu Server. Спроектирована и описана архитектура интеграции Harbor в учебный процесс (CI/CD пайплайны для проверки лабораторных работ).
*   **Стек:** Docker, Harbor, GitLab CI, Ubuntu Server.

### 4. Кроссплатформенный UDP-мессенджер
Разработка приложения для закрытой производственной коммуникации в локальной сети.
*   **Что сделано:** Разработан собственный протокол передачи данных поверх UDP с поддержкой фрагментации и сборки больших сообщений. Создан графический интерфейс с историей сообщений и настройками сети.
*   **Стек:** C++, Qt5, UDP, QDataStream.
