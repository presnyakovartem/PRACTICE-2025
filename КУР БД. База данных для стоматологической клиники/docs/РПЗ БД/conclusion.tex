\ssr{ЗАКЛЮЧЕНИЕ}

В результате выполнения курсовой работы была разработана база данных и программное приложение для хранения и обработки стоматологических снимков челюсти человека.

В ходе выполнения работы были решены следующие задачи:

\begin{itemize}
	\item проведён анализ предметной области;
	\item рассмотрены существующие программные решения;
	\item определены основные сущности предметной области;
	\item спроектирована база данных;
	\item выполнена нормализация базы данных до третьей нормальной формы;
	\item реализована связь многие-ко-многим между врачами и клиниками;
	\item разработана ролевая модель базы данных;
	\item реализованы функция и триггер на стороне PostgreSQL;
	\item разработано приложение доступа к базе данных;
	\item реализовано Redis-кэширование;
	\item выполнено логирование с использованием библиотеки \texttt{spdlog};
	\item реализован графический интерфейс пользователя на Qt 6;
	\item подготовлены тестовые данные объёмом не менее 1000 записей в каждой таблице;
	\item проведено исследование влияния индексов на время выполнения запросов.
\end{itemize}

Таким образом, цель курсовой работы была достигнута.
