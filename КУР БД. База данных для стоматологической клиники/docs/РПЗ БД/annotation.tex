\ssr{РЕФЕРАТ}

Расчетно-пояснительная записка содержит сведения о проектировании и реализации базы данных для хранения и обработки стоматологических снимков челюсти человека.

БАЗА ДАННЫХ, PostgreSQL, СТОМАТОЛОГИЧЕСКИЙ СНИМОК, МЕДИЦИНСКАЯ КАРТА, РЕЛЯЦИОННАЯ МОДЕЛЬ, ДИАГНОЗ, Redis, C++, libpqxx.

Цель работы: проектирование и разработка информационной системы для хранения сведений о пациентах стоматологической клиники, медицинских картах, цифровых снимках челюсти, врачебных заключениях, клиниках, оборудовании и типах исследований.

В ходе работы выполняется анализ предметной области, формализация требований к базе данных и приложению доступа, проектирование реляционной схемы базы данных, разработка приложения доступа к данным, реализация внешнего кэширования с использованием Redis, проектирование ролевой модели на уровне базы данных, а также исследование влияния индексов на время выполнения запросов.

В качестве системы управления базами данных используется PostgreSQL. Приложение доступа к данным разрабатывается на языке C++ с использованием библиотеки libpqxx. Для проверки работоспособности бизнес-логики и слоя доступа к данным используется технологический консольный интерфейс, работающий с тем же компонентом бизнес-логики, что и будущий графический интерфейс.
